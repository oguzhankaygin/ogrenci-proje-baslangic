Öğrenci Proje Başlangıç Paketi

Python, JavaScript, Java ve C ders projeleri için test, README ve takım şablonlarıyla hazır iskelet. Ücretsiz ve açık kaynak.

1. Claude Code ile

Claude Code oturumunda şu iki komutu çalıştır:

/plugin marketplace add oguzhankaygin/ogrenci-proje-baslangic
/plugin install ogrenci-proje@ogrenci-proje-baslangic
  • /ogrenci-proje:proje-baslat [ad]: iskeleti oluşturur ve testi çalıştırır.
  • /ogrenci-proje:ipucu [konu]: öğrenme modunda sıradaki tek ipucunu verir.
  • /ogrenci-proje:teslim-kontrol: testleri, belgeleri, TODO'ları ve Git kayıtlarını denetler.

2. Yalnızca Python ile (Claude gerekmez)

Depoyu ZIP olarak indir, klasörde şunu çalıştır (Python 3.10+):

python3 plugin/skills/proje-baslat/scripts/baslat.py --ad odev-1 --dil python --tur bireysel --ders "BLM101"

--dil: python, javascript, java, c · --tur: bireysel, takim · --kuru: yalnızca dosya listesini göster.

3. Ücretsiz Claude hesabıyla öğrenme modu

Kurulum yapamıyorsan, öğrenme modu kurallarını sohbete taşıyan hazır istemi kopyala. Claude çözümü vermek yerine adım adım ipucuyla ilerler.

Diğer ücretsiz öğrenci araçları

  • Sokratik Ders Çalışma Koçu: konuyu sorularla çalış.
  • Ders Bazlı Yapay Zekâ Rehberi: dersin YZ kurallarını netleştir.
  • Türkçe Yazım ve Biçim Denetçisi: ödev metnini denetle.
  • Kaynakça Denetçisi: APA/IEEE kaynakçanı kontrol et.
  • Staj ve CV Koçu: CV'ni ilana göre iyileştir.
  • Burs, Yurt ve Staj Takvimi: son tarihleri kaçırma.
  • Burs Başvuru Atölyesi: başvuru metnini güçlendir.
